# Predictive Adaptive 2.5D Mapping

React/Vite frontend prototype for demonstrating predictive adaptive 2.5D LiDAR mapping with adaptive information budgeting.

## Stack

- React
- Vite
- Tailwind CSS
- Lucide React
- Recharts
- Framer Motion

## Run On Windows

Open PowerShell in this folder and run:

```powershell
npm install
npm run dev
```

Then open the local URL Vite prints, usually:

```text
http://localhost:5173
```

## Notes

The simulation is frontend-only. It does not connect to real LiDAR hardware or a backend.
